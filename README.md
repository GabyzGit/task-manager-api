# Task Manager API 🚀

API RESTful para gerenciamento de tarefas desenvolvida como projeto acadêmico focado na aplicação de **Gestão Ágil** e práticas **Lean**.

---

## 📌 Propósito do Projeto
O objetivo principal da **Task Manager API** é fornecer uma interface leve e eficiente para o ciclo de vida completo de tarefas (CRUD). O desenvolvimento seguiu os princípios Lean de eliminação de desperdícios e entrega contínua de valor através de um MVP (Minimum Viable Product).

---

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Node.js (JavaScript / ES6+)
- **Framework Web:** Express.js
- **Testes Automatizados:** Jest e Supertest
- **Gestão do Projeto:** GitHub Issues & GitHub Projects (Kanban)
- **Controle de Versão:** Git & GitHub
